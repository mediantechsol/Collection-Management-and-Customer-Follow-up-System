# 🏥 حزمة التشخيص والفحص الشامل لقاعدة البيانات (Database Health & Diagnostics Suite)

تم إنشاء هذه الحزمة المتكاملة في مجلد `supabase/diagnostics/` لتوفير أدوات فحص وتدقيق عميقة تكشف أي مشكلات خفية، ثغرات أمنية، أو خلل في سلامة البيانات.

---

## 📁 ملفات الاستعلامات والغرض منها:

| الملف | الهدف والوظيفة | متى يُستخدم؟ |
|---|---|---|
| **`00_master_health_check.sql`** | **الاستعلام الشامل الموحد** (يعيد فحصاً كاملاً للجداول، الأمان RLS، الدوال، السجلات اليتيمة، والمحفزات دفعة واحدة). | **موصى به كفحص أولي سريع.** |
| **`01_schema_integrity.sql`** | فحص المفاتيح الأساسية (Primary Keys)، الـ Views، وحالة `security_invoker`. | عند تعديل أو إضافة جداول جديدة. |
| **`02_security_and_rls_audit.sql`** | فحص سياسات الأمان RLS على الجداول ومستودعات التخزين (Storage) لمنع أي تسريب بيانات. | للتدقيق الأمني الدوري. |
| **`03_data_integrity_and_orphans.sql`** | اكتشاف السجلات اليتيمة (Orphaned Records) أو القيم الفارغة والشاذة في الحقول الأساسية. | بعد عمليات الاستيراد والاستعادة الكبيرة. |
| **`04_triggers_and_automation.sql`** | فحص المحفزات التلقائية (Triggers)، سجل التدقيق (Audit Logs)، وتوليد الحوافز والتنبيهات. | للتأكد من استجابة النظام التلقائية. |
| **`05_performance_and_indexes.sql`** | فحص فهارس المفاتيح الأجنبية وتحديد الاستعلامات التي تحتاج تسريع، مع أحجام الجداول. | لتحسين سرعة واستجابة النظام. |

---

## 🚀 طريقة الاستخدام:
1. افتح **Supabase Dashboard** ثم توجه إلى **SQL Editor**.
2. انسخ محتوى الملف المطلوب (أو ملف `00_master_health_check.sql`).
3. الصقه واضغط **Run**.
4. راجع جدول النتائج؛ أي سطر يحمل علامة ❌ أو 🚨 أو ⚠️ يشير إلى نقطة تحتاج انتباهاً أو تحسيناً.
