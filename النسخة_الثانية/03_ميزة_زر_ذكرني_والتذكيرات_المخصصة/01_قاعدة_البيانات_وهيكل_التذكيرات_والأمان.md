### 🎯 1. بطاقة وسياق المهمة (Context & Scope)
بناء المخطط البرمجي والأمني لنظام التذكيرات الحرة المخصصة على مستوى قاعدة البيانات (PostgreSQL / Supabase)، وتطبيق سياسات حماية على مستوى الصف (RLS) تضمن عزل تذكيرات كل مستخدم بشكل تام ومطلق، مع كتابة دوال RPC للتعامل مع العمليات الشائعة (الإنشاء السريع، التعليم كمكتمل، والتأجيل السريع)، ودمج الأنواع وخطافات React Query في كود الواجهة.

### 🔍 2. مرحلة التحليل والاستكشاف (Phase 1: Analysis & Discovery)

1. **الفرق بين التذكيرات الحرة (`custom_reminders`) وتنبيهات النظام الرسمية (`notifications`):**
   - **تنبيهات النظام (`notifications`):** تتولد آلياً بواسطة `generate_daily_notifications()` أو يدوياً برفع الحالة للمدير (`escalated`)، ومرتبطة بقواعد استحقاق الديون وانقطاع المتابعة.
   - **التذكيرات الحرة (`custom_reminders`):** تذكيرات مرنة ينشئها المحصل أو المستخدم لأي سبب (مثل: "اتصل به بعد المغرب"، "طلب إرسال كشف حساب بالواتساب"، "زيارة المحل صباح الثلاثاء") وتاريخ استحقاقها حر تماماً.
2. **الربط الاختياري بالعميل (Optional Customer Association):**
   - يمكن ربط التذكير بـ `customer_id` معين (وهو الشائع)، أو تركه فارغاً (`null`) إذا كان التذكير عاماً (مثل: "مراجعة إدارة الحسابات لاستلام سندات جديدة").
3. **مراعاة توقيت الاستحقاق وحالات التذكير:**
   - الحالات الأساسية: `is_completed` (هل تم إنجازه أم لا).
   - حالات التاريخ:
     - **مستحق اليوم (Due Today):** `due_date = current_date` و `!is_completed`.
     - **متأخر (Overdue):** `due_date < current_date` و `!is_completed`.
     - **قادم (Upcoming):** `due_date > current_date` و `!is_completed`.
     - **مكتمل (Completed):** `is_completed = true`.

### 📐 3. مرحلة التصميم والمعمارية (Phase 2: Architecture & Design)

#### أ. جدول التذكيرات المخصصة (`custom_reminders`):
```sql
create table if not exists public.custom_reminders (
  id              uuid primary key default gen_random_uuid(),
  user_id         uuid not null references public.users(id) on delete cascade,
  customer_id     uuid references public.customers(id) on delete cascade,
  title           text not null,
  notes           text,
  due_date        date not null,
  due_time        time,
  priority        text not null default 'normal' check (priority in ('low', 'normal', 'high', 'urgent')),
  is_completed    boolean not null default false,
  completed_at    timestamptz,
  snoozed_until   date,
  created_at      timestamptz not null default now(),
  updated_at      timestamptz not null default now()
);

-- فهارس الأداء السريع
create index if not exists idx_custom_reminders_user on public.custom_reminders(user_id);
create index if not exists idx_custom_reminders_user_date on public.custom_reminders(user_id, due_date);
create index if not exists idx_custom_reminders_customer on public.custom_reminders(customer_id);
create index if not exists idx_custom_reminders_status on public.custom_reminders(user_id, is_completed);
```

#### ب. سياسات الحماية على مستوى الصف (RLS):
```sql
alter table public.custom_reminders enable row level security;

-- عزل كامل: لا يرى المستخدم ولا يعدل إلا تذكيراته الخاصة
create policy custom_reminders_user_policy on public.custom_reminders
  for all
  using (auth.uid() = user_id)
  with check (auth.uid() = user_id);
```

#### ج. دوال الـ RPC المساعدة:

1. **`create_custom_reminder`**: دالة إنشاء تذكير سريع مع التحقق الأمني:
   ```sql
   create or replace function public.create_custom_reminder(
     p_customer_id uuid,
     p_title text,
     p_notes text,
     p_due_date date,
     p_due_time time default null,
     p_priority text default 'normal'
   )
   returns public.custom_reminders
   language plpgsql
   security definer
   set search_path = public
   as $$
   declare
     v_user_id uuid := auth.uid();
     v_res public.custom_reminders;
   begin
     if v_user_id is null then
       raise exception 'يجب تسجيل الدخول لإنشاء تذكير';
     end if;
     if coalesce(trim(p_title), '') = '' then
       raise exception 'عنوان التذكير مطلوب';
     end if;

     insert into public.custom_reminders (
       user_id, customer_id, title, notes, due_date, due_time, priority
     ) values (
       v_user_id, p_customer_id, trim(p_title), p_notes, p_due_date, p_due_time, coalesce(p_priority, 'normal')
     )
     returning * into v_res;

     return v_res;
   end;
   $$;
   ```

2. **`toggle_reminder_status`**: دالة تعليم التذكير كمكتمل أو غير مكتمل بنقرة واحدة:
   ```sql
   create or replace function public.toggle_reminder_status(
     p_reminder_id uuid,
     p_is_completed boolean
   )
   returns public.custom_reminders
   language plpgsql
   security definer
   set search_path = public
   as $$
   declare
     v_user_id uuid := auth.uid();
     v_res public.custom_reminders;
   begin
     if v_user_id is null then
       raise exception 'غير مصرح';
     end if;

     update public.custom_reminders
     set
       is_completed = p_is_completed,
       completed_at = case when p_is_completed then now() else null end,
       updated_at = now()
     where id = p_reminder_id and user_id = v_user_id
     returning * into v_res;

     if v_res.id is null then
       raise exception 'التذكير غير موجود أو لا تملك صلاحية تعديله';
     end if;

     return v_res;
   end;
   $$;
   ```

3. **`snooze_reminder`**: دالة تأجيل التذكير بعدد محدد من الأيام:
   ```sql
   create or replace function public.snooze_reminder(
     p_reminder_id uuid,
     p_days_to_add integer
   )
   returns public.custom_reminders
   language plpgsql
   security definer
   set search_path = public
   as $$
   declare
     v_user_id uuid := auth.uid();
     v_res public.custom_reminders;
   begin
     if v_user_id is null then
       raise exception 'غير مصرح';
     end if;
     if p_days_to_add <= 0 then
       raise exception 'عدد أيام التأجيل يجب أن يكون أكبر من الصفر';
     end if;

     update public.custom_reminders
     set
       due_date = current_date + p_days_to_add,
       snoozed_until = current_date + p_days_to_add,
       is_completed = false,
       completed_at = null,
       updated_at = now()
     where id = p_reminder_id and user_id = v_user_id
     returning * into v_res;

     return v_res;
   end;
   $$;
   ```
