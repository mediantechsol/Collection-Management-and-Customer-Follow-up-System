# 📄 برومبت المهمة 2: مودال «ذكرني» السريع ونقاط الاستدعاء في النظام
## المرحلة: الثانية (RemindMeModal, Quick Presets & System Trigger Integration)
## الموديول: زر «ذكرني» والتذكيرات الحرة المخصصة (V2 - Module 3)

---

### 🎯 1. بطاقة وسياق المهمة (Context & Scope)
بناء نافذة ومودال تفاعلي سريع فائق السلاسة (`RemindMeModal.tsx`) يتيح لمسؤول التحصيل إنشاء تذكير حر بنقرة واحدة مع خيارات مسبقة ذكية (غداً، بعد 3 أيام، بعد أسبوع، بعد أسبوعين، أو تاريخ مخصص)، ومقترحات سريعة لنوع المهمة، ودمج زر "⏰ ذكرني" في كل نقاط التفاعل الحيوية بالنظام (شاشة المتابعة اليومية، ملف العميل، وبطاقات التنبيهات).

---

### 🔍 2. مرحلة التحليل والاستكشاف (Phase 1: Analysis & Discovery)

1. **نقاط استدعاء زر "ذكرني" (Trigger Entry Points):**
   - **في شاشة المتابعة (`FollowupsScreen.tsx`):**
     - إضافة خيار أو زر سريع "⏰ ذكرني" بجانب زر [تسجيل متابعة] في كل صف من صفوف الجدول.
   - **في شاشة تفاصيل العميل (`CustomerDetailScreen.tsx`):**
     - زر أنيق في ترويسة بطاقة العميل بجانب أزرار الإجراءات (تعديل، إضافة متابعة، إضافة دفعة).
   - **في مركز التنبيهات (`NotificationsScreen.tsx`):**
     - زر سريع داخل البطاقات التفاعلية وزر رئيسي أعلى الشاشة `[ ➕ تذكير جديد ]`.
2. **عناصر تجربة المستخدم والسرعة (UX Speed):**
   - **أزرار الجدولة المسبقة (Quick Date Presets):**
     - `[ غداً ]` (+1 يوم)
     - `[ بعد 3 أيام ]` (+3 أيام)
     - `[ بعد أسبوع ]` (+7 أيام)
     - `[ بعد أسبوعين ]` (+14 يوماً)
     - `[ مخصص ]` (منتقي التاريخ والوقت الحر)
   - **المقترحات السريعة لعنوان التذكير (Quick Suggestions Chips):**
     - `[ 📞 اتصال هاتفي ]` `[ 🏢 زيارة ميدانية ]` `[ 📄 إرسال كشف حساب ]` `[ 🤝 تأكيد وعد سداد ]` `[ ⚠️ متابعة ضمانة ]`
   - النقر على المقترح يملأ حقل العنوان فوراً بضغطة زر واحدة.

### 💻 4. مرحلة التنفيذ البرمجي (Phase 3: Implementation)

#### أ. إنشاء مكون المودال:
`app/src/features/reminders/RemindMeModal.tsx`
- نافذة منبثقة تعتمد على مكون `Modal` المشترك في النظام.
- استقبال الخصائص:
  ```typescript
  interface Props {
    open: boolean;
    onClose: () => void;
    customerId?: string | null;
    customerName?: string | null;
    initialTitle?: string;
  }
  ```
- إدارة حالة الحقول (Title, Notes, DueDate, DueTime, Priority).
- حساب التواريخ بناءً على دالة التاريخ المعتمدة بتوقيت اليمن `todayInYemen()`.
- الربط مع طفرة `useCreateCustomReminder()` وعرض Toast نجاح: `تم ضبط التذكير بنجاح`.

#### ب. دمج زر الاستدعاء في شاشة المتابعة (`FollowupsScreen.tsx`):
- إضافة خيار استدعاء `setRemindCustomer(customer)` لفتح المودال.
- إضافة أيقونة زر منبه أنيق `IconClock / IconBell` في عمود الإجراءات أو القائمة السريعة للصف.

#### ج. دمج زر الاستدعاء في شاشة تفاصيل العميل (`CustomerDetailScreen.tsx`):
- وضع زر `⏰ ذكرني` في شريط الإجراءات العلوي للعميل بجانب أزرار المتابعة والدفعات.
