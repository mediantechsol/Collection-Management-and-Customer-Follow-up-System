## الموديول: مركز النسخ الاحتياطي والاستعادة من الواجهة (V2 - Module 4)

### 🎯 1. بطاقة وسياق المهمة (Context & Scope)
إجراء الفحص الشامل والتحقق الصارم من استقرار وموثوقية ميزة النسخ الاحتياطي والاستعادة، بما يشمل كتابة اختبارات الوحدة المؤتمتة (Vitest) لفحص ومعالجة حزم البيانات والـ Checksum، وتنفيذ محاكاة عملية كاملة لاختبار التعافي من الكوارث (Disaster Recovery Drill)، والتأكد من مطابقة البيانات المستعادة بنسبة 100% دون أي فقدان أو خلل في المفاتيح الأجنبية، وتقديم التقرير ودليل الاعتماد النهائي للمستخدم.

---

### 🔍 2. سيناريوهات الاختبار والتحقق (Test Matrix & Scenarios)

1. **اختبارات وحدة الواجهة (Vitest Unit Tests):**
   - التحقق من دالة فحص وتدقيق هيكل حزمة النسخة الاحتياطية (`validateBackupPayloadFormat`).
   - التحقق من حساب أحجام الملفات وتحويلها لوحدات مفهومة (Bytes -> KB -> MB).
   - التحقق من معالجة الأخطاء عند رفع ملفات تالفة أو غير متوافقة برمجياً.

2. **اختبارات عزل الصلاحيات والأمان (RLS & Security Checks):**
   - محاولة استدعاء دوال الـ RPC من حساب مستخدم عادي (محصل أو محاسب) والتأكد من الرفض القاطع على مستوى قاعدة البيانات (`raise exception`).

3. **محاكاة التعافي الكارثي العملية (End-to-End Disaster Recovery Drill):**
   * **الخطوة 1:** تصدير لقطة كاملة لقاعدة البيانات الحالية وحفظ الـ Payload كمرجع (`Baseline Snapshot`).
   * **الخطوة 2:** إجراء تعديلات عشوائية متعمدة (إضافة عملاء وهميين، تعديل أرصدة، إضافة متابعات جديدة، حذف إعدادات).
   * **الخطوة 3:** تنفيذ عملية الاستعادة الشاملة باستخدام ملف الـ Baseline.
   * **الخطوة 4:** مقارنة ومطابقة كافة الجداول والسجلات مع الحالة الأصلية والتأكد من التطابق بنسبة 100% مع إنشاء نقطة أمان قبل الاستعادة بنجاح.

### 💻 3. كود اختبارات الوحدة (Vitest Implementation)

إنشاء ملف `app/src/lib/backupRestore.test.ts`:
```typescript
import { describe, it, expect } from 'vitest';

describe('Backup & Restore Payload Validation Engine', () => {
  const validPayload = {
    manifest: {
      format_version: '2.0',
      app_version: 'SCP-V2',
      backup_type: 'manual',
      backup_id: 'test-uuid-1',
      backup_name: 'Test Backup',
      file_name: 'backup_test.json',
      created_at: new Date().toISOString(),
      created_by_username: 'admin',
      created_by_user_id: 'user-uuid-1',
      table_counts: { customers: 2, balances: 2, followups: 3 }
    },
    tables: {
      settings: [{ id: true, usd_rate: 530 }],
      customer_categories: [{ id: 'cat-1', name: 'مزارع أ' }],
      customers: [{ id: 'cust-1', name: 'عميل تجريبي' }],
      balances: [{ id: 'bal-1', customer_id: 'cust-1', currency: 'YER', current_balance: 100000 }],
      followups: [{ id: 'fol-1', customer_id: 'cust-1', notes: 'متابعة أولى' }],
      collections: [],
      incentives: [],
      due_dates: [],
      custom_reminders: []
    }
  };

  it('should pass validation for a well-formed V2 backup payload', () => {
    expect(validPayload.manifest.format_version).toBe('2.0');
    expect(validPayload.tables).toHaveProperty('customers');
    expect(validPayload.tables).toHaveProperty('custom_reminders');
    expect(Array.isArray(validPayload.tables.customers)).toBe(true);
  });

  it('should reject payload with missing manifest or tables', () => {
    const invalidPayload = { tables: {} };
    expect((invalidPayload as any).manifest).toBeUndefined();
  });

  it('should reject incompatible format versions', () => {
    const oldPayload = {
      manifest: { format_version: '0.5' },
      tables: {}
    };
    expect(oldPayload.manifest.format_version).not.toBe('2.0');
  });
});
```
